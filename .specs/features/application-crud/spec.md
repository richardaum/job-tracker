# Application CRUD — Spec

**Milestone:** M1
**Status:** Planned

## Requirements

| ID    | Description                                                                    |
| ----- | ------------------------------------------------------------------------------ |
| AC-01 | Create a job application with title, company, URL, and date                    |
| AC-02 | List all applications belonging to the authenticated user                      |
| AC-03 | Edit any field of an existing application                                      |
| AC-04 | Delete an application (owner only)                                             |
| AC-05 | All operations are scoped to the owner — users cannot access each other's data |
