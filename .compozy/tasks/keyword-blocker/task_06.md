# Task 06: Settings UI

## Overview

Add a "Blocked Keywords" collapsible section to the `SettingsTabPage` in the Profile settings. Users can view, add, and delete blocked keywords (with scope and match mode) and manage a list of blocked company names. Each change calls `updateSettings` with the full updated arrays, following the existing per-field save pattern (optimistic response, pending state).

- Read PRD § Core Features 4 (Settings UI) and TechSpec § Settings UI
- Follow existing SettingCard pattern with pending state and optimisticResponse
- Update `settings.graphql` query and mutation to include new fields
- Tests required
</critical>
