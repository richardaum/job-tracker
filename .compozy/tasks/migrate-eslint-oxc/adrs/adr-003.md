# ADR-003: Import Sorting via OXC (Replace `scripts/fix-imports.ts` + `simple-import-sort`)

## Status

Accepted

## Date

2026-05-29

## Context

Import sorting is currently handled by two mechanisms:

1. `scripts/fix-imports.ts` — custom TypeScript script that reorders imports
2. `eslint-plugin-simple-import-sort` — ESLint plugin for import ordering

Both run on every `lint-staged` invocation. OXC's formatter (`oxfmt`) has built-in import/export sorting via the `sort` command, and the OXC import plugin also provides import ordering rules. The user chose to let OXC handle import sorting natively.

## Decision

Replace both `scripts/fix-imports.ts` and `eslint-plugin-simple-import-sort` with OXC's native sorting:

- Configure import sorting rules in `.oxlintrc.json` using the `import` plugin's `import/order` rule
- Remove `scripts/fix-imports.ts` and its invocation from lint-staged and CI
- Remove `eslint-plugin-simple-import-sort` from root `devDependencies`
- Verify sorting output matches current behavior (same grouping and ordering conventions)

## Alternatives Considered

### Alternative 1: Keep `scripts/fix-imports.ts` + use OXC only for lint

- **Description**: Continue running the custom sort script in pre-commit; OXC handles only error/warning lint rules.
- **Pros**: Zero change to import sorting behavior.
- **Cons**: Extra pre-commit step; duplicate sorting logic.
- **Why rejected**: User chose OXC for import sorting natively.

### Alternative 2: OXC import plugin via `oxlint --fix-imports`

- **Description**: Use OXC's `--fix` + import plugin for sorting, but keep the custom script as a safety net.
- **Pros**: Fallback if OXC sort order differs.
- **Cons**: Two sort paths can conflict; maintenance burden.
- **Why rejected**: Unnecessary complexity.

## Consequences

### Positive

- Single tool for both linting and import sorting
- Removes custom script maintenance burden
- Removes one ESLint plugin dependency
- Faster pre-commit (no Node.js script startup for sorting)

### Negative

- OXC import sort order may differ from current behavior — must review diff and adjust config or accept minor ordering differences
- `scripts/fix-imports.ts` removal must be coordinated with any CI or external tooling that calls it directly

### Risks

- If OXC import sorting does not match the team's preferred convention, configuration options may be more limited than a fully custom script
