# ADR-001: @ai Mention with Streaming for Job Notes

## Status

Accepted

## Date

2026-06-01

## Context

The notes system on job details pages lacks AI integration. Users currently switch context to use AI features elsewhere. We need a natural way to ask AI about a job's context (title, description, company, match, notes) directly from the notes composer, with the response posted as a note.

The notes composer uses TipTap editor, which already supports AI actions (Improve note, Rewrite text) but not free-form AI questioning.

## Decision

Implement "@ai" as a mention trigger in the TipTap notes editor with streaming AI response:

1. User types `@` → popover with available mentions (starts with "AI", extensible for future)
2. User selects "AI" → inline mention chip inserted
3. User types their question after the mention
4. On submit, the prompt is sent to AI service with job context (job, company, match, notes)
5. AI response streams via GraphQL Subscription into a new note with "AI" badge
6. Each interaction is isolated — no threading or conversation history

Phase 2 may add function calling tools (search other jobs, fetch more data).

## Alternatives Considered

### A2: @ai with threaded conversation

- **Description**: AI responses grouped in threads, user can ask follow-ups
- **Pros**: Richer interaction, natural conversation flow
- **Cons**: Higher complexity, new UI for threading, changes notes data model
- **Why rejected**: MVP doesn't need conversation history; threading can be added later if users show demand

### AI sidebar / dedicated chat tab

- **Description**: Separate AI chat panel instead of @ai in notes
- **Pros**: Dedicated space for AI interaction, no changes to notes editor
- **Cons**: Context switching, requires new tab/sidebar UI, doesn't integrate with notes workflow
- **Why rejected**: User specifically wants @ai integration in the notes flow

## Consequences

### Positive

- Natural UX — users already type notes, now can ask AI in the same place
- Leverages existing notes infrastructure (TipTap, NoteType, NotesPanel)
- Streaming gives immediate feedback
- Extensible mention system for future @-mentions

### Negative

- Requires TipTap mention extension (new dependency)
- New Subscription endpoint for streaming AI responses
- AI responses mixed with human notes — needs clear AI badge

### Risks

- AI latency could feel slow if streaming is not well-implemented
- Users may abuse @ai for non-job-related questions — mitigation: include job context in system prompt
- API costs increase with each @ai invocation — mitigation: rate limiting in Phase 2 if needed

## Implementation Notes

- TipTap `@mention` extension with async suggestions
- `AiBaseService` subclass for chat-style responses with streaming
- GraphQL Subscription for streaming response (follow `jobs-events.resolver.ts` pattern with EventBus)
- NoteType gets an `isAiGenerated` boolean field
- Context: job fields (title, description, company, match analysis) + recent notes
